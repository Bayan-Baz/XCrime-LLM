# Data

The experiments in XCrime-LLM use the NYPD Complaint Data Historic dataset provided by NYC Open Data.

The original dataset can be obtained from:

https://data.cityofnewyork.us/Public-Safety/NYPD-Complaint-Data-Historic/qgea-i56i

After downloading the dataset, place the CSV file in your Google Drive or local data directory and update `DATA_PATH` in the preprocessing notebook.
